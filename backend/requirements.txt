# REPRODUCIBILITY (Phase 8.1)
# ---------------------------
# Every requirement carries an UPPER bound. Previously only langgraph and
# langchain-core were pinned and everything else was floored with `>=` and no
# ceiling, so `pip install -r requirements.txt` resolved differently depending
# on the day it was run. A training run is only reproducible if the stack
# under it is: numpy and torch have both changed RNG or default-dtype
# behaviour across minor versions in ways that move model weights.
#
# Upper bounds are set at the next MAJOR (or the next minor for pre-1.0
# packages), which blocks a breaking release without freezing out patches.
#
# For an exact, byte-identical environment use the lockfile instead:
#
#     pip install -r requirements.lock      # exact versions, reproducible
#     pip install -r requirements.txt       # ranges, for development
#
# Regenerate the lock after ANY change to this file:
#
#     python -m venv .venv && . .venv/bin/activate
#     pip install -r requirements.txt
#     pip freeze --exclude-editable > requirements.lock
